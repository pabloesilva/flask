# 📒 AGENDA con Flask CRUD 1.6

Una aplicación web sencilla y elegante de agenda de contactos desarrollada con **Python Flask**, **MySQL** y **Bootstrap** (tema [Bootswatch Brite](https://bootswatch.com/brite/)).

Incluye:
- Registro e inicio de sesión con contraseñas cifradas.
- Gestión CRUD de contactos.
- Interfaz adaptable con **modo claro/oscuro** seleccionable.
- Sistema de sesión y protección de rutas.

---

## 🚀 Funcionalidades

- ✅ Registro y autenticación de usuarios
- ✅ Agregar, editar y eliminar contactos
- ✅ Flash messages con feedback visual
- ✅ Tema claro/oscuro con selector visual desde la navbar
- ✅ Protección de rutas con decorador `@require_login`
- ✅ Validación de formularios y nombres de usuario únicos

---

## 🖥️ Tecnologías utilizadas

| Herramienta       | Descripción                                      |
|-------------------|--------------------------------------------------|
| Flask             | Microframework de backend en Python              |
| Flask-MySQLdb     | Conexión con base de datos MySQL/MariaDB         |
| Bootstrap 5.3     | Framework CSS para diseño responsive             |
| Bootswatch Brite  | Tema moderno para Bootstrap                      |
| Jinja2            | Motor de plantillas                             |
| Werkzeug          | Seguridad de contraseñas (hashing `scrypt`)      |
